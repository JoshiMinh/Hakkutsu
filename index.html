Everything You Need for Immersion Mining

Designed for Japanese learners wanting fast, seamless vocabulary acquisition while reading articles, manga, or documentation.

Smart Inline Dictionary

Instant morphological analysis with Sudachi & Kuromoji. Highlights pitch accents, furigana, JLPT levels (N5–N1), and Sino-Vietnamese (Hán-Việt) sounds.

Offline Screenshot OCR

Crop any region of your screen to extract Japanese kanji & vertical text offline using Tesseract OCR (`jpn` & `jpn_vert`) inside a Chrome MV3 Offscreen Worker.

AI Grammar Breakdown

Connect your own Gemini or OpenAI key to receive deep sentence breakdowns, idiom explanations, and contextual translations on demand.

AnkiConnect Sync

Export target vocabulary, sentence context, audio, and definitions directly to your local Anki deck with a single click.

Built-in Spaced Repetition

No Anki? No problem. Review saved vocabulary using Hakkutsu's built-in local SRS dashboard with interval scheduling and memory tracking.

Privacy First & Offline

All dictionary lookups, tokenizer data, and SRS cards remain strictly local on your device. Zero user data tracking.

Chrome Extension Installation Guide

Install Hakkutsu in 3 Easy Steps

Compatible with Chrome, Microsoft Edge, Brave, and all Chromium browsers.

1

Download Extension Package

Download the prebuilt Hakkutsu Chrome extension package (.zip):

Download Hakkutsu (.zip)
2

Open Chrome Extensions & Enable Developer Mode

Navigate to chrome://extensions in your browser address bar and turn ON Developer mode using the toggle in the upper right corner.

3

Drag & Drop to Install

Simply drag and drop the downloaded chrome-mv3-prod.zip file onto the Chrome extensions page:

"Drop a ZIP or CRX file here or select a file."

Chrome will automatically extract and activate Hakkutsu instantly!
