# Hakkutsu Feature Roadmap

- [x] **Synchronized Subtitle Script Drawer ("Reader Mode for Video"):** Provides a collapsible transcript sidebar on YouTube, Netflix, and HTML5 video players featuring auto-scrolling synced to video playback, full-text dialogue search, 1-click cue seeking, and real-time highlighting of known vs. unlearned vocabulary
- [ ]  **Client-Side Box OCR for Manga & Images:** Integrates lightweight WebAssembly OCR (`tesseract.js` / ONNX) to let users drag a bounding box over manga scans, canvas elements, and web comics to extract and parse Japanese text without external APIs.
